# Acceptable Use of AI Coding Tools

**Policy owner:** [Privacy Officer / Security Officer]
**Effective date:** [Date]
**Review cadence:** Annual
**Applies to:** All workforce members, contractors, and business associates with access to [Company Name] systems.

## 1. Purpose
Define how AI-assisted coding tools (Claude Code, Claude.ai, GitHub Copilot, ChatGPT, Cursor, and similar) may be used at [Company Name], a HIPAA-covered entity operating outpatient physical therapy clinics.

## 2. Approved tools
The following tools are approved for use, subject to the conditions in §3:

| Tool | Approved for PHI? | Conditions |
|------|-------------------|------------|
| Claude Code (Enterprise) | Yes | BAA on file; managed `settings.json` deployed; audit logging enabled |
| Claude.ai (Enterprise/Team) | Yes, if BAA executed | Otherwise de-identified data only |
| Anthropic API direct | Yes | BAA on file; logged through company gateway |
| Any other AI tool | **No** | Use prohibited until reviewed by Privacy Officer |

## 3. Permitted data classes
- **Public / non-sensitive** (marketing copy, public policies, generic code): Permitted in any approved tool.
- **Internal / confidential** (financials, employee info, internal docs): Permitted only in tools with BAA or enterprise data-protection terms.
- **PHI** (any 18 HIPAA Safe Harbor identifier tied to health data): Permitted **only** in tools listed above as "Yes" with BAA on file. PHI may **never** be pasted into a personal account, free-tier AI tool, or any tool not on the approved list.

## 4. Required practices
- Use company-issued laptops only. Personal devices are prohibited.
- Authenticate with company SSO; do not log in with personal accounts.
- Do not disable telemetry, audit logging, or marketplace restrictions.
- Synthetic or de-identified data is the default for development. Real PHI access requires Privacy Officer approval and a documented business need.
- Code generated by AI tools is reviewed by a human before merge, per the Plugin Development Standard.

## 5. Prohibited practices
- Sending PHI to any tool without a current, executed BAA.
- Installing AI plugins, extensions, or marketplaces outside the approved allowlist.
- Storing API keys, credentials, or secrets in prompts, code, or plugin manifests.
- Using AI-generated code in production without human review.
- Bypassing managed settings, EDR, or other endpoint controls.

## 6. Incident reporting
Any suspected unauthorized disclosure, misconfiguration, or AI-related security event must be reported to [security@company.com] within 1 hour of discovery. See the Incident Response Addendum for procedure.

## 7. Sanctions
Violations are subject to [Company Name]'s standard HIPAA sanctions policy, up to and including termination.

## 8. Acknowledgment
All workforce members with access to AI coding tools must sign an acknowledgment annually.
